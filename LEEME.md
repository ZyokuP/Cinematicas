# Cine Cámara (Forge 1.20.1)

Todos los comandos son solo para operadores.

1. Colócate donde quieras que empiece la cámara, mira hacia donde quieras y escribe `/cine punto`.
2. Repite en cada punto clave (muévete, gira, `/cine punto`...).
3. `/cine ver` dibuja el camino con partículas (fuego = puntos, línea = camino).
4. `/cine tiempo 30s` fija la duración total.
5. `/cine play` la reproduce para ti, o `/cine play @a` para todos.  `/cine stop` la detiene.

Otros: `/cine quitar`, `/cine borrar`, `/cine lista`, `/cine usar <nombre>` (varias cinemáticas).
Las cinemáticas se guardan en el mundo y sobreviven a reinicios.

## Obtener el .jar sin instalar nada
1. Sube TODO el contenido de esta carpeta (incluida `.github`) a un repositorio de GitHub.
2. Pestaña Actions -> "Compilar mod" -> descarga **cinecamara-jar**.
3. Pon el .jar en la carpeta `mods` del servidor y de cada jugador.
